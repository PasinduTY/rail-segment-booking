# Segment-Based Train Seat Booking System

Booking system for Sri Lanka's Colombo Fort–Badulla line, where a single reserved
seat can be booked independently for multiple non-overlapping legs of the journey.

> Work in progress — design decisions and setup instructions will be filled in as
> the project develops.

## Stack

- **Backend:** .NET (ASP.NET Core Web API)
- **Database:** PostgreSQL
- **Frontend:** React + TypeScript (Vite)
- **Run:** Docker Compose
